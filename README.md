# Arrow Escape — by Waqar Ahmad

Original arrow-grid puzzle game for Android.

## Requirements
- Android Studio (current version)
- JDK compatible with your Android Studio
- Android SDK 36

Android Studio can import an Empty Activity Compose project, and Jetpack Compose is officially supported by Google.

## Build APK
Open this folder in Android Studio, let Gradle sync, then:
Build → Build Bundle(s) / APK(s) → Build APK(s)

Debug APK:
app/build/outputs/apk/debug/app-debug.apk

## Game
Tap an arrow only when its path to the edge is clear. Clear all arrows to complete the level. Levels grow from 3×3 to 6×6.

This is an original implementation and does not include Amaze GO assets or code.
